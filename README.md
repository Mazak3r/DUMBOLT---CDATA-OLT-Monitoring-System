# DUMBOLT---CDATA-OLT-Monitoring-System
DUMBOLT (Dynamic Unified Monitoring for Broadband Optical Line Terminals) is a Streamlit-based web app giving network engineers real-time visibility into CDATA OLTs. It centralizes ONU/ONT monitoring across multiple devices, tracks signal strength, detects port movements, and enables one-click reboots through an intuitive dashboard.
